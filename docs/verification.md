## 自动化覆盖

后端测试实际执行 PDF 解析、SQLite 读写和 API 路由，覆盖作答前不泄漏答案、资源归属、首答唯一约束、补练误区匹配、不同题复测状态推进、猜对复查、上传限制、解析硬超时、选项与引用归属、预算拦截、有限重试、日志脱敏、后台恢复和种子导出隔离。

本轮增加了误区能否被原文反驳、独立选项误区映射、主题依据不足时拒绝、上传落盘失败不残留排队资料、不足误区批次恢复、种子导出不能覆盖运行数据库等检查。AI 工作台接口检查覆盖资料归属、示例调用计数为 0，以及不返回凭证或答案。普通题目接口不返回目标误区名称；已答错后进入补练才显示已揭示的目标误区，刷新后仍保留补练标签。

前端测试覆盖多层补练返回路径恢复、断网后保留轮次、生成任务恢复、手动填写候选知识点、信心必须主动选择、接口失败与空记录的区别、同页证据上下文去重，以及答案快捷键和 Enter 提交条件。新增真实日志字段渲染回归，覆盖成功、失败、中断状态及用途名称。HTTP 与浏览器环境边界使用受控替身；组件和状态保存逻辑实际执行。测试没有替代浏览器操作验收。

本次从首页一键开始后，故意将“可删除容器中间元素”判为符合标准栈，并选择“确定”。系统显示“认为栈可任意删除”，原文只高亮直接纠正这一判断的句子。随后完成链式栈节点地址情境的补练，复习页进入“纠正中”；新一轮的 `pop` 删除位置复测答对后，显示“近期已纠正”。最终统计为累计作答 3 题、答对 2 题、待纠正误区 0 个。

## 验证边界

实时模式工程测试采用受控模拟供应商，没有配置真实服务凭证，因此不能据此声称供应商已接通、真实生成质量达标、费用已测定或达到生成时延目标。供应商未返回 token 用量时，日志默认值也不能解释为免费调用。种子内容由编码助手离线编写，尚未经过独立人工审定或真实模型盲答复核。

浏览器验证使用 8765 端口，因为当前环境的 8000 端口无法绑定。系统未安装 Docker，没有执行镜像构建或容器启动。测试期间有 Starlette 对 httpx 测试客户端的弃用提示，未影响当前结果。

技术 PDF、视频、源码 ZIP 和 Git bundle 的交付检查见 [本地提交审计](submission-audit.md)。视频由真实页面操作截图、普通话合成解说和字幕制作；它展示无 Key 示例流程，不是连续真人录屏或真实模型调用证据。页数、时长和文件格式通过检查，也不能替代赛事官方对内容的审核。
