# 演示脚本

当前视频为真实页面操作截图、逐句字幕与普通话合成解说，不是连续真人录屏或真实模型调用证据。分镜和完整旁白见 `video-storyboard.json`；所有画面不包含团队、学校或成员身份。

1. 首页一键“用示例讲义练 3 题”；展示 8 页讲义、4 知识点、12 个误区和 48 道离线示例题。
2. 以标准栈能否任意删除为情境，选择错误选项及“确定”，主动记录作答信心。
3. 提交后左右对照题目和讲义原文，说明“认为栈可任意删除”，阅读四个选项的具体解析。
4. 展示直接依据的黄色高亮、纠正句下划线、同页上下文合并和手机底部原文面板。
5. 点击“针对这个误区再练一道”，完成链式栈节点地址情境；复习页显示“纠正中”。
6. 进入新一轮，完成自动混入的 `pop` 删除位置复测；复习页显示“近期已纠正”。状态描述近期练习表现，不代表长期掌握。
7. 打开 AI 工作台，依次展开解析与分句、混合 RAG、误区建模、结构化出题、独立盲答与有限修复、学习闭环。
8. 展示数据库中的真实课程片段及误区实体。示例模式显示 0 次真实模型调用、无虚构 token 和耗时；模型配置可展开。
9. 介绍工程验证：73 项后端、15 项前端测试及生产构建通过。说明尚待配置真实服务、开展内容审定和用户评测。
10. 说明技术创新、应用价值、本地交付内容和后续安排。

视频采用 1920×1080、H.264/AAC MP4，保持 5–8 分钟。实际时长与检查记录以 `submission/check-results.json` 为准。使用 Windows 普通话合成声音，已在视频中明确标注。

真实模型录制应在配置有效凭证并完成验收后进行：文本 PDF → 候选知识点 → 用户确认 → 检索与误区生成 → 质量复核 → 入库。保留真实失败和依据不足状态，不用示例片段代替真实生成结果。
