# 演示脚本

建议使用全新浏览器会话，服务以无 Key 演示模式启动。下面是录制脚本，不代表已经完成真人测试或比赛视频。

1. 资料页展示常驻「演示模式」以及示例题来源说明。打开一个知识点，说明覆盖度是已入库题数，不是学习掌握度。
2. 选择知识点开始三题小测。展示选项和三个信心按钮，说明答案不会提前发到浏览器。
3. 故意选一个错误答案并选择「确定」。提交后阅读「你可能……」误区提示和每个选项的解释。
4. 点击查看原文，展示文件名、物理页码、原文上下文和高亮纠正句。引文来自句子表，不由模型重新摘写。
5. 点击「针对这个误区再练一道」。对照新题与旧题，完成作答。
6. 复习页观察误区从待纠正变为纠正中。再开一轮，完成自动混入的复测题，观察近期已纠正状态。
7. 展示信心统计以及猜对题目的复查入口。解释这些状态仅描述本会话的练习表现。
8. 有有效模型凭证时再演示上传：文本 PDF → 候选知识点 → 用户确认 → 后台题库生成。展示真实失败和依据不足状态，不跳过或替换成假结果。

录制前检查：页面缩放、中文字体、无密钥进入画面、浏览器会话隔离、录屏分辨率与赛事要求相符。比赛规则、视频时长和 PDF 页数由团队依据官方要求核对。
