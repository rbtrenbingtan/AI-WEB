# 前端改版验收

日期：2026-11-17。依据团队提供的《知证学伴·前端验收报告与修改方案 V3》，结合已确认的“完整前端改版、增加可展开 AI 工作台、更新提交材料”范围实施。浏览器验收视口为 1440×900 与 390×844，使用无 Key 示例资料。

## V3 九项验收

| 要求 | 当前结果 | 核验依据 |
| --- | --- | --- |
| 无小于 12px 的字号 | 通过 | CSS 中字号均引用六级变量，最小为 12px |
| 全站最多六级字号 | 通过 | 32 / 24 / 18 / 16 / 14 / 12px；字重为 400 / 500 / 600 |
| 统一配色、移除绿色 | 通过 | 15 个颜色变量统一为墨蓝、蓝色、橙色和黄色；组件无硬编码十六进制颜色；阴影使用方案指定的墨蓝透明色 |
| 无英文装饰标题 | 通过 | 已删除旧侧栏、页头与卡片中的英文口号；AI、RAG、Token 等技术名称仅用于工作台信息表达 |
| 清除重复免责声明与实现提示 | 通过，按后续授权调整范围 | 学习页面删除原有脚注、Cookie 提示、句子 ID 与来源兜底文案；事实来源和验收边界保留在文档，模型技术集中在 AI 工作台 |
| 不加载 Google Fonts、不使用 Georgia | 通过 | 界面使用系统无衬线字体，课程引文使用系统宋体类字体；数字使用界面字体 |
| 示例证据最多高亮三句 | 通过 | 全部 48 题各引用 1–2 句直接依据，合并误区纠正句后最多 3 句；自动化检查数量与归属，演示路径浏览器核对内容 |
| 四次点击内进入纠错闭环 | 通过 | 一键开始 → 选择错误答案 → 选择信心 → 提交；桌面随即出现原文和补练入口 |
| 390px 无横向滚动或裁切 | 通过 | 手机首页、原文面板、AI 工作台实测；没有装饰插画，内容宽度未超出视口 |

V3 原文要求界面不出现实现原理，之后团队明确要求在网页展示大模型技术并确认增加 AI 工作台，因此本版将技术展示放入独立页面。课程题干中的“仅”“可能”等正常语义不按界面免责声明删除。保留的错误提示与上传格式信息用于指导实际操作。

## 页面与行为

资料页提供首屏一键练习，侧栏宽度 200px，只保留品牌和四项导航；删除旧顶栏、全局页脚、插画和重复介绍卡。上传未启用时隐藏入口。知识点可以展开查看每个误区的题数。

练习页作答后直接在选项下显示解析，正确为蓝色对勾，错误为橙色叉号；步骤条同步显示真实对错。桌面右侧自动呈现原文，按页合并相邻上下文，黄色标记直接证据，误区纠正句加下划线。学习页面只显示“第 N 页”，不展示内部句子编号。手机改用底部原文面板，支持关闭、Escape 和焦点管理。

补练题显示已揭示的目标误区，当前题目位置及多层返回路径保存到本地存储；网络中断后保留位置并提供重试。普通未作答题不提前暴露目标误区。A–D / 1–4 选择选项，Enter 只在选择答案和信心后提交。

复习页保留累计作答、答对和待纠正误区三个指标；误区列表显示具体记录，信心矩阵使用“确定 / 没把握”，猜对题合并进最近练习。补练按钮按被点击题目的 ID 显示加载状态，其他行不会一起转圈。

AI 工作台展示解析分句、混合 RAG、误区建模、Schema 约束出题、复核修复、学习闭环六个阶段。课程片段、误区、已入库题数和调用记录通过后端读取；模型配置可展开。当前清楚标为“示例流程”，真实调用次数为 0，平均耗时显示“—”。阶段说明用于介绍已实现的实时流程，不把示例题标成已经历真实模型复核。

## 内容与代码

已将全部 48 道种子题的证据缩减到 1–2 句，误区纠正依据缩减到直接相关句子；重写第一个知识点 12 道题的四个选项解析，直接解释具体错误。改写由编码助手完成，尚待团队独立内容审定，不记作人工审定结果。

前端样式表重新组织为可读的分区规则。生产前端源码不使用 `any` 或 `else`，通过类型与判别联合表达数据状态，局部状态优先使用 `const`。网络、浏览器存储和文件输入等实际系统边界保留必要校验及错误处理；没有为了满足关键词扫描删除有效的失败反馈。后端保留模型输出、资源归属和文件解析边界的业务检查。

15 项前端测试与 73 项后端测试通过，TypeScript 和生产构建通过，依赖审计当次为 0 个漏洞。前端测试实际执行组件、状态恢复、证据合并和快捷键逻辑；真实模型调用没有纳入本次验收。
