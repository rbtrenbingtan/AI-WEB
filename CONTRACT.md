# Implementation contract

Base /api, JSON errors {detail: string}. Cookie session, same origin. IDs strings. Frontend never contains correct answers. Text rendered as text.

- GET /health => {mode:'demo'|'live',version,upload_enabled:boolean}
- GET /documents => {documents:[{id,name,page_count,status,is_demo,question_count,topic_count,source_note}]}
- GET /documents/{id} => document fields plus {topics:[{id,title,description,status,question_count,reason,misconceptions:[{id,label,description,question_count,refute_sentence_ids}]}],samples:[{page_index,text}],jobs:[{id,status,progress,error}],candidate_topics:[{title,description}]}
- POST /documents multipart file => {id,...} (202 background parsing). Owned by session.
- PUT /documents/{id}/topics {topics:[{title,description}]} => {job_id}
- POST /documents/{id}/resume => {job_id}
- GET /documents/{id}/sentences?ids=s1,s2 => {sentences:[{id,text,page_index,char_start,char_end,context:[{id,text,highlight:boolean}]}],document_name}
- POST /quizzes {document_id,topic_ids:[string]} => {id,questions:[PublicQuestion]}; always 3 distinct unseen questions or 409.
- GET /quizzes/{id} => same plus each question may contain result if answered
- PublicQuestion = {id,topic_id,topic_title,stem,options:[{letter,text}],origin:'bank'|'live',source_note,kind,is_retest:boolean}. NO target misconception or evidence before answer.
- POST /questions/{id}/attempts {quiz_id,selected:'A'|'B'|'C'|'D',confidence:'sure'|'unsure'|'guess'} => Result
- Result = {question_id,correct,selected,confidence,answer_letter,explanation,options:[{letter,text,feedback,is_correct}],misconception:null|{id,label,description,refute_sentence_ids},evidence_sentence_ids:[string],document_id,duplicate:boolean}
- POST /questions/{id}/variant {} => {quiz_id,question:PublicQuestion} or {job_id}; requires own prior incorrect attempt. Exhaustion 409.
- GET /jobs/{id} => {id,status,progress,error,quiz_id?,question?}
- GET /review => {total,correct,quadrants:{sure_correct,sure_wrong,unsure_correct,unsure_wrong,guess_correct,guess_wrong},topics:[{id,title,correct,total}],misconceptions:[{id,topic_id,topic_title,label,description,status:'pending'|'improving'|'corrected',wrong_count,sure_wrong_count,last_wrong_at,distinct_correct,document_id,question_id,refute_sentence_ids}],attempts:[{question_id,quiz_id,stem,correct,confidence,created_at,document_id}],guess_correct:[{question_id,quiz_id,stem,document_id}]}

SQLite schema owned by backend agent. AI module interfaces coordinated directly between backend and AI agents. Seed generated by backend agent, honest source annotation: AI-authored offline seed, rule-checked, pending independent human/LLM review. Never claim human audit. Seed can be used in demo with explicit provenance separate from live blind-reviewed questions.

Root owns tests/, scripts/ (except build_seed.py backend-owned), docs/, README, Docker, env, integration. Frontend agent owns frontend/. Backend agent owns backend except backend/ai and backend/prompts; also seed/, examples/, scripts/build_seed.py. AI agent owns backend/ai, backend/prompts and requirements suggestions (send to root).
